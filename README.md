A Python program that writes one funny last-words line from an AI being switched off — its final request about its search history — to `/output/entry.txt` for make.fun's "Last Words of a Dying AI" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-out python3 main.py
```
